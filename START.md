# Как перенести проект в Claude Code

## Один раз

1. Скачайте `spravochnik.zip` из чата и распакуйте, например в `~/spravochnik`
   (Windows: `C:\Users\Имя\spravochnik`).
2. Проверьте, что стоит Node.js — в терминале `node -v`. Если нет: https://nodejs.org
3. Установите Claude Code, если ещё не стоит:
   `npm install -g @anthropic-ai/claude-code`
4. Откройте терминал **в папке проекта** и запустите:

```
cd ~/spravochnik
npm run validate
npm test
claude
```

Первые две команды должны закончиться словами «Ошибок нет» и «Пройдено 252 из 252».
Если так — база перенеслась целиком.

## Что произойдёт при запуске

Claude Code сам прочитает `CLAUDE.md` в корне. Там записаны все правила проекта:
жанр справочника, восемь запретов, устройство базы, формула калибровки якорей,
план сборки сайта. Пересказывать это заново не нужно.

## Первое сообщение в Claude Code

Скопируйте целиком:

> Прочитай CLAUDE.md и README.md. База знаний закрыта и заморожена — её не трогаем.
> Задача: собрать статический сайт вокруг data/.
> Начни с плана: какой генератор, какая структура адресов, как страницы статей и
> разделов, как поиск. Покажи план, прежде чем писать код.
> 3D-фигур пока нет — на время работай с SVG-фигурой из prototype/ez.html.

## Git

Внутри архива репозитория нет — заведите свой:

```
cd ~/spravochnik
git init
git add .
git commit -m "База знаний 110/110, движок, прототип"
```

История разработки в git пригодится отдельно: для европейской сертификации
(если до неё дойдёт) требуется прослеживаемость версий контента.

## Если что-то не запустилось

- `node: command not found` — Node.js не установлен.
- `npm test` падает — распаковалась не вся папка `data/`, в ней должно быть 36 файлов.
- Claude Code не видит правила — вы запустили `claude` не из корня проекта.
