## Что где

| Папка | Что внутри |
|---|---|
| `data/` | База знаний, 36 файлов JSON. Заморожена |
| `src/` | Движок ранжирования — тот же код идёт на сайт |
| `tools/` | Валидатор базы |
| `docs/` | Концепция, устройство базы, ТЗ 3D-художнику |
| `prototype/` | Рабочий прототип: один файл, открывается двойным щелчком |

**`CLAUDE.md` в корне — правила проекта.** Читается автоматически при запуске Claude Code; прочитать стоит и человеку.

## Порядок работы

База закрыта. Дальше строится сайт вокруг неё: статический генератор, постоянный адрес у каждой статьи, модель тела, поиск, страница «что здесь не разбирают».

После любой правки данных — `npm run validate` и `npm test`. Оба должны заканчиваться без ошибок.
